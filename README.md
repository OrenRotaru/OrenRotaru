**Right now** I'm on the software sub-team for the **RADSAT-SK2 / CUBICS** CubeSat mission, bringing up the on-board computer — Rust mission applications on a Buildroot Linux image, running on top of the Kubos flight-software framework, with a cross-compile + Docker build pipeline. Getting the satellite's modules to boot, talk, and recover the way they're supposed to.

**Some things I've built**
- **A custom 8-bit microcontroller** in Verilog — my own ISA, program sequencer, instruction decoder, computational unit, and program/data memory, synthesized and run on an FPGA. The lab where CPUs finally clicked for me.
- **Computer-vision-driven congestion control** (contributed to a friend's repo) — using CV to infer network conditions and adapt flow. A rare systems-meets-ML project.
- **A home lab** running Docker on Linux — self-hosted media streaming, family photo storage, and game servers for friends. The invisible-but-satisfying plumbing kind of work.
- **Automation and scrapers** for when a website won't hand over its data cleanly.

**What I care about**
- Software architecture — how pieces fit together, and whether the shape will still make sense in a year.
- UI that feels good to use. Dense where it needs to be, quiet where it doesn't.
- The Linux/Docker/networking layer under everything. Server admin, infra, the stuff that holds up.
- Visual storytelling — videography and photography are a long-time love that school swallowed for a while. Trying to get back to it.
